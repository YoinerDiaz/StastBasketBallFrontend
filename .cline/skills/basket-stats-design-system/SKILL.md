# Basket Stats Design System

This is the project-specific visual system for Basket Stats.

All frontend visual work should follow this skill unless the user explicitly requests a different design direction.

## Product identity

Basket Stats is a university basketball statistics application.

The visual identity should communicate:

- basketball
- competition
- statistics
- performance
- technology
- professionalism

The interface should look like a real sports statistics platform rather than a generic CRUD application.
